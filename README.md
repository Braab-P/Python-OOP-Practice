# 🐍 Python & OOP Practice

Этот репозиторий содержит коллекцию моих учебных и практических задач по основам Python и объектно-ориентированному программированию (ООП). 

## 📂 Содержание:
* `01_guess_number.py` — текстовая игра на угадывание числа (циклы, работа с `random`).
* `02_rpg_characters.py` — реализация игровых персонажей с использованием наследования, инкапсуляции и полиморфизма.
* `03_library_publications.py` — система учета публикаций (книги и журналы) с переопределением методов.
* `04_vehicles.py` — модель транспортных средств (классы, наследование, счетчики экземпляров).
* `05_ghost_hunter.py` — полноценная текстовая игра-квест с игровым циклом, состоянием игрока и случайной генерацией событий.
* `06_caesar_cipher.py` — модифицированный шифр Цезаря. Динамический сдвиг букв в каждом слове зависит от количества букв в этом слове. Обработка текста через sys.stdin.
* `07_password_validator.py` — скрипт для валидации паролей по трем условиям (палиндром, простое число, четность) с обработкой исключений.
* `08_string_algorithms.py` — набор функций для работы со строками: проверка баланса скобок, поиск палиндромов, вычисление расстояния Хэмминга (разница в 1 символ), конвертация CamelCase в snake_case.
* `09_list_and_math_algorithms.py` — алгоритмы для работы с числами и списками: поиск следующего простого числа (оптимизированный O(sqrt(N))), слияние K отсортированных списков (merge sort), удаление дубликатов с сохранением порядка.
* `10_sorting_algorithms.py` — ручная реализация алгоритмов сортировки: пузырьковой (Bubble Sort) и выбором (Selection Sort).
* `11_math_algorithms.py` — алгоритм поиска числа с максимальной суммой делителей в заданном диапазоне.

## 🚀 Как запустить
Каждый файл является независимым скриптом. Для запуска используйте:
```bash
python <имя_файла>.py
